🗂️ GitHub Pages 缓存清理工具

ℹ️ 使用说明

GitHub Pages 的缓存通常需要几小时才能自动过期。以下方法可以立即清理缓存：

  1. 推荐方法：访问带有版本参数的URL，强制刷新缓存
  2. 手动方法：在浏览器中按 Ctrl+Shift+R (Windows) 或 Cmd+Shift+R (Mac)
  3. 彻底方法：清除浏览器缓存或使用无痕模式

💡 自动清理缓存的更多方法

方法1：Service Worker（推荐）

点击"注册Service Worker"按钮，下次访问时将自动清理缓存

方法2：版本化文件名

在HTML中引用资源时添加版本号：

<script src="js/app.js?v=20241208"></script>

方法3：GitHub Actions（自动化）

已在仓库中添加 .github/workflows/clear-cache.yml，每次推送都会自动清理缓存
