## 1. 项目概述

### 1.1 改造目标

将现有的**车辆位置分享系统 Web 应用**改造为**微信小程序**，提供更优的移动端体验和更强的微信生态集成能力。

### 1.2 核心价值

| 维度 | Web 版 | 小程序版 | 优势 |
|------|--------|----------|------|
| **启动速度** | 需打开浏览器 | 微信内直接打开 | ⚡ 更快 |
| **用户体验** | 依赖浏览器性能 | 原生组件性能 | 📱 更流畅 |
| **分享能力** | 下载图片 | 小程序卡片、转发 | 🎯 更强社交属性 |
| **定位精度** | 浏览器API | 小程序原生API | 🎯 更准确 |
| **离线使用** | 不支持 | 支持缓存 | 💾 更好 |

### 1.3 功能范围

**保留功能：**
- ✅ 车辆选择系统（4辆家庭车辆）
- ✅ 实时定位
- ✅ 地图展示与标记
- ✅ 地图截图分享
- ✅ 位置信息复制
- ✅ 地址解析

**新增功能：**
- 🆕 微信原生分享（转发给好友）
- 🆕 扫码快速选择车辆
- 🆕 历史位置记录（可选）
- 🆕 消息推送（位置更新提醒）

## 5. 核心模块改造方案

### 5.1 定位模块改造

#### 当前实现

```javascript
// js/location.js
class LocationManager {
    getCurrentPosition(options = {}) {
        return new Promise((resolve, reject) => {
            navigator.geolocation.getCurrentPosition(
                (position) => {
                    const location = this._processPosition(position);
                    resolve(location);
                },
                error => reject(error),
                { enableHighAccuracy: true, timeout: 20000 }
            );
        });
    }

    _processPosition(position) {
        const wgsLat = position.coords.latitude;
        const wgsLng = position.coords.longitude;
        // 手动转换坐标
        const gcjCoords = this.wgs84ToGcj02(wgsLat, wgsLng);
        return {
            lat: gcjCoords.lat,
            lng: gcjCoords.lng,
            // ...
        };
    }
}
```

#### 小程序实现

```javascript
// utils/location.js
class LocationManager {
  /**
   * 获取当前位置
   * @param {Object} options 定位选项
   * @returns {Promise<Object>} 位置信息
   */
  getCurrentPosition(options = {}) {
    return new Promise((resolve, reject) => {
      wx.getLocation({
        type: 'gcj02',  // 直接返回 GCJ-02 坐标
        altitude: true,
        accuracy: 'best',
        success: (res) => {
          const location = this._processLocation(res);
          resolve(location);
        },
        fail: (err) => {
          console.error('定位失败:', err);
          // 使用默认位置
          resolve(this._getDefaultLocation());
        }
      });
    });
  }

  /**
   * 处理定位结果
   * @param {Object} res 微信定位结果
   * @returns {Object} 标准化位置信息
   */
  _processLocation(res) {
    return {
      latitude: res.latitude,
      longitude: res.longitude,
      accuracy: res.accuracy || 0,
      altitude: res.altitude || 0,
      speed: res.speed || 0,
      timestamp: Date.now(),
      provider: '微信小程序定位',
      accuracyLevel: this._getAccuracyLevel(res.accuracy),
      quality: this._calculateQuality(res)
    };
  }

  /**
   * 持续定位
   * @param {Function} callback 位置回调
   */
  watchPosition(callback) {
    wx.startLocationUpdate({
      success: () => {
        wx.onLocationChange(callback);
      }
    });
  }

  /**
   * 停止持续定位
   */
  stopWatch() {
    wx.stopLocationUpdate();
    wx.offLocationChange();
  }
}

module.exports = LocationManager;
```

**改造要点：**
- ✅ 移除坐标转换逻辑（小程序直接返回 GCJ-02）
- ✅ 使用 `wx.getLocation` 替代 `navigator.geolocation`
- ✅ 简化代码结构

**方案A：Canvas 2D 绘制（推荐）**

```javascript
// utils/screenshot.js
class ScreenshotManager {
  /**
   * 生成地图截图
   * @param {Object} mapData 地图数据
   * @param {Object} carInfo 车辆信息
   * @param {Object} location 位置信息
   * @returns {Promise<string>} 图片临时路径
   */
  async generateScreenshot(mapData, carInfo, location) {
    return new Promise((resolve, reject) => {
      // 1. 获取地图静态图
      this._getMapStaticImage(mapData, location)
        .then(imagePath => {
          // 2. 在 Canvas 上绘制
          const ctx = wx.createCanvasContext('screenshotCanvas');

          // 绘制地图底图
          ctx.drawImage(imagePath, 0, 0, 600, 400);

          // 绘制中心标记
          this._drawMarker(ctx, carInfo);

          // 绘制信息卡片
          this._drawInfoCard(ctx, carInfo, location);

          // 3. 导出图片
          ctx.draw(false, () => {
            wx.canvasToTempFilePath({
              canvasId: 'screenshotCanvas',
              success: (res) => resolve(res.tempFilePath),
              fail: reject
            });
          });
        })
        .catch(reject);
    });
  }

  /**
   * 获取地图静态图
   */
  async _getMapStaticImage(mapData, location) {
    return new Promise((resolve, reject) => {
      // 使用腾讯地图静态图 API
      const url = `https://apis.map.qq.com/ws/staticmap/v2/` +
        `?center=${location.latitude},${location.longitude}` +
        `&zoom=${mapData.scale}` +
        `&size=600x400` +
        `&maptype=roadmap` +
        `&markers=color:red|${location.latitude},${location.longitude}` +
        `&key=${TENCENT_MAP_KEY}`;

      // 下载图片到本地
      wx.downloadFile({
        url: url,
        success: (res) => resolve(res.tempFilePath),
        fail: reject
      });
    });
  }

  /**
   * 绘制车辆标记
   */
  _drawMarker(ctx, carInfo) {
    const centerX = 300;
    const centerY = 200;
    const color = carInfo.color;

    // 外圈发光
    const gradient = ctx.createRadialGradient(centerX, centerY, 0, centerX, centerY, 30);
    gradient.addColorStop(0, this._hexToRgba(color, 0.3));
    gradient.addColorStop(1, this._hexToRgba(color, 0));
    ctx.setFillStyle gradient);
    ctx.beginPath();
    ctx.arc(centerX, centerY, 30, 0, 2 * Math.PI);
    ctx.fill();

    // 主标记
    ctx.setFillStyle(color);
    ctx.beginPath();
    ctx.arc(centerX, centerY, 20, 0, 2 * Math.PI);
    ctx.fill();

    // 车辆图标
    ctx.drawImage(carInfo.logoPath, centerX - 14, centerY - 20, 28, 28);

    // 车辆名称
    ctx.setFillStyle('#fff');
    ctx.setFontSize(12);
    ctx.fillText(carInfo.name, centerX, centerY + 35);
  }

  /**
   * 绘制信息卡片
   */
  _drawInfoCard(ctx, carInfo, location) {
    const cardY = 320;

    // 背景
    ctx.setFillStyle('rgba(0, 0, 0, 0.7)');
    ctx.fillRect(20, cardY, 560, 70);

    // 车辆信息
    ctx.setFillStyle('#fff');
    ctx.setFontSize(18);
    ctx.fillText(`🚗 ${carInfo.name}`, 40, cardY + 25);

    ctx.setFontSize(14);
    ctx.fillText(`📍 ${carInfo.plate}`, 40, cardY + 50);

    // 时间
    const time = util.formatTime(new Date(location.timestamp));
    ctx.setTextAlign('right');
    ctx.fillText(`🕒 ${time}`, 560, cardY + 25);
    ctx.setTextAlign('left');
  }

  /**
   * Hex 转 RGBA
   */
  _hexToRgba(hex, alpha) {
    const r = parseInt(hex.slice(1, 3), 16);
    const g = parseInt(hex.slice(3, 5), 16);
    const b = parseInt(hex.slice(5, 7), 16);
    return `rgba(${r}, ${g}, ${b}, ${alpha})`;
  }
}

module.exports = ScreenshotManager;
```

// pages/index/index.js
const VEHICLE_CONFIG = require('../../config/vehicle.js');

Page({
  data: {
    vehicles: []
  },

  onLoad() {
    // 加载车辆配置
    const vehicles = Object.values(VEHICLE_CONFIG);
    this.setData({ vehicles });
  },

  /**
   * 选择车辆
   */
  onVehicleSelect(e) {
    const { carId } = e.currentTarget.dataset;
    const vehicle = VEHICLE_CONFIG[carId];

    // 保存到全局数据
    const app = getApp();
    app.globalData.currentVehicle = vehicle;

    // 跳转到地图页
    wx.navigateTo({
      url: `/pages/map/map?carId=${carId}`
    });
  },

  /**
   * 扫码选择车辆
   */
  onScanCode() {
    wx.scanCode({
      success: (res) => {
        // 解析二维码中的车辆ID
        const carId = this._parseCarIdFromQR(res.result);
        if (carId && VEHICLE_CONFIG[carId]) {
          this.onVehicleSelect({
            currentTarget: { dataset: { carId } }
          });
        } else {
          wx.showToast({
            title: '无效的车辆二维码',
            icon: 'none'
          });
        }
      },
      fail: () => {
        wx.showToast({
          title: '扫码失败',
          icon: 'none'
        });
      }
    });
  },

  /**
   * 从二维码解析车辆ID
   */
  _parseCarIdFromQR(qrContent) {
    // 假设二维码格式：https://xxx.com?car=car001
    const match = qrContent.match(/[?&]car=([^&]+)/);
    return match ? match[1] : null;
  }
});

// pages/map/map.js
const VEHICLE_CONFIG = require('../../config/vehicle.js');
const LocationManager = require('../../utils/location.js');
const MapManager = require('../../utils/map.js');
const QQMapWX = require('../../lib/qqmap-wx-jssdk/index.js');

const app = getApp();
const qqmap = new QQMapWX({
  key: app.globalData.config.mapKey
});

Page({
  data: {
    currentVehicle: null,
    mapData: {
      longitude: 116.397477,
      latitude: 39.908692,
      scale: 18,
      markers: [],
      showLocation: true
    },
    location: {
      address: '',
      accuracy: 0,
      timeStr: ''
    }
  },

  locationManager: null,
  mapManager: null,

  onLoad(options) {
    const { carId } = options;
    const vehicle = VEHICLE_CONFIG[carId];

    if (!vehicle) {
      wx.showToast({
        title: '车辆信息不存在',
        icon: 'none'
      });
      setTimeout(() => {
        wx.navigateBack();
      }, 1500);
      return;
    }

    // 初始化
    this.setData({ currentVehicle: vehicle });
    this.locationManager = new LocationManager();
    this.mapManager = new MapManager();

    // 开始定位
    this.startLocation();
  },

  /**
   * 开始定位
   */
  async startLocation() {
    wx.showLoading({ title: '定位中...' });

    try {
      // 获取位置
      const location = await this.locationManager.getCurrentPosition();
      const app = getApp();
      app.globalData.currentLocation = location;

      // 更新地图
      this.updateMap(location);

      // 逆地理编码
      this.reverseGeocode(location);

    } catch (error) {
      console.error('定位失败:', error);
      wx.showToast({
        title: error.message || '定位失败',
        icon: 'none'
      });
    } finally {
      wx.hideLoading();
    }
  },

  /**
   * 更新地图
   */
  updateMap(location) {
    const marker = this.mapManager.createMarker(location, this.data.currentVehicle);

    this.setData({
      mapData: {
        ...this.data.mapData,
        longitude: location.longitude,
        latitude: location.latitude,
        markers: [marker]
      },
      location: {
        ...this.data.location,
        accuracy: Math.round(location.accuracy),
        timeStr: this.formatTime(new Date(location.timestamp))
      }
    });
  },

  /**
   * 逆地理编码
   */
  reverseGeocode(location) {
    qqmap.reverseGeocoder({
      location: {
        latitude: location.latitude,
        longitude: location.longitude
      },
      success: (res) => {
        const address = res.result.address;
        this.setData({
          'location.address': address
        });
      },
      fail: (error) => {
        console.error('逆地理编码失败:', error);
      }
    });
  },

  /**
   * 刷新定位
   */
  async onRefreshLocation() {
    await this.startLocation();
    wx.showToast({
      title: '位置已更新',
      icon: 'success'
    });
  },

  /**
   * 截图分享
   */
  async onScreenshot() {
    wx.showLoading({ title: '生成中...' });

    try {
      const ScreenshotManager = require('../../utils/screenshot.js');
      const screenshotManager = new ScreenshotManager();

      const imagePath = await screenshotManager.generateScreenshot(
        this.data.mapData,
        this.data.currentVehicle,
        getApp().globalData.currentLocation
      );

      wx.hideLoading();

      // 预览图片
      wx.previewImage({
        urls: [imagePath],
        current: imagePath
      });

    } catch (error) {
      wx.hideLoading();
      console.error('截图失败:', error);
      wx.showToast({
        title: '截图失败',
        icon: 'none'
      });
    }
  },

  /**
   * 地图区域变化
   */
  onMapRegionChange(e) {
    console.log('地图区域变化:', e);
  },

  /**
   * 点击标记
   */
  onMarkerTap(e) {
    console.log('点击标记:', e);
  },

  /**
   * 格式化时间
   */
  formatTime(date) {
    const year = date.getFullYear();
    const month = String(date.getMonth() + 1).padStart(2, '0');
    const day = String(date.getDate()).padStart(2, '0');
    const hour = String(date.getHours()).padStart(2, '0');
    const minute = String(date.getMinutes()).padStart(2, '0');
    return `${year}-${month}-${day} ${hour}:${minute}`;
  },

  /**
   * 分享配置
   */
  onShareAppMessage() {
    return {
      title: `${this.data.currentVehicle.name} 位置分享`,
      path: `/pages/map/map?carId=${this.data.currentVehicle.id}`,
      imageUrl: ''  // 可使用生成的截图
    };
  }
});

### 11.2 推荐方案：Canvas 2D + 静态图

**实现流程：**

```
1. 获取地图静态图（腾讯地图API）
       ↓
2. 创建离屏Canvas
       ↓
3. 绘制地图底图
       ↓
4. 绘制车辆标记
       ↓
5. 绘制信息卡片
       ↓
6. 导出为临时文件
       ↓
7. 分享/保存
```

**代码实现：**

```javascript
// utils/screenshot.js
class ScreenshotManager {
  /**
   * 生成完整截图
   */
  async generateScreenshot(mapData, carInfo, location) {
    const ctx = wx.createCanvasContext('screenshotCanvas');

    // 1. 绘制地图底图
    await this._drawMapBase(ctx, mapData, location);

    // 2. 绘制中心标记
    this._drawCenterMarker(ctx, carInfo);

    // 3. 绘制信息卡片
    this._drawInfoCard(ctx, carInfo, location);

    // 4. 导出图片
    return await this._exportImage();
  }

  /**
   * 绘制地图底图（使用静态图API）
   */
  async _drawMapBase(ctx, mapData, location) {
    // 腾讯地图静态图API
    const mapUrl = `https://apis.map.qq.com/ws/staticmap/v2/` +
      `?center=${location.latitude},${location.longitude}` +
      `&zoom=${mapData.scale}` +
      `&size=600x400` +
      `&maptype=roadmap` +
      `&markers=color:0x${carInfo.color.slice(1)}|${location.latitude},${location.longitude}` +
      `&key=${MAP_KEY}`;

    // 下载图片
    const imagePath = await this._downloadImage(mapUrl);

    // 绘制到Canvas
    ctx.drawImage(imagePath, 0, 0, 600, 400);
  }

  /**
   * 下载网络图片
   */
  _downloadImage(url) {
    return new Promise((resolve, reject) => {
      wx.downloadFile({
        url: url,
        success: (res) => resolve(res.tempFilePath),
        fail: reject
      });
    });
  }

  /**
   * 导出图片
   */
  _exportImage() {
    return new Promise((resolve, reject) => {
      ctx.draw(false, () => {
        wx.canvasToTempFilePath({
          canvasId: 'screenshotCanvas',
          success: (res) => resolve(res.tempFilePath),
          fail: reject
        });
      });
    });
  }
}

module.exports = ScreenshotManager;
```

#### 17.2.2 地图标记实现（cover-view 方案）

#### 17.2.3 截图功能实现（Canvas 2D API）

**问题**：使用旧版 Canvas API (`wx.createCanvasContext`) 时，截图只显示左上 1/4 内容。

**根本原因**：
1. 旧版 Canvas API 使用 rpx 单位，导致尺寸计算错误
2. 异步图片加载没有正确处理

**解决方案**：改用新版 Canvas 2D API (`wx.createOffscreenCanvas`)。

**实际代码** (`miniprogram/utils/screenshot.js`):

```javascript
async generateScreenshot(mapData, carInfo, location) {
  // 创建离屏 Canvas
  const canvas = wx.createOffscreenCanvas({
    type: '2d',
    width: this.canvasWidth,
    height: this.canvasHeight
  });

  const ctx = canvas.getContext('2d');

  // 异步加载地图图片
  const mapImage = canvas.createImage();
  await new Promise((resolve) => {
    mapImage.onload = resolve;
    mapImage.src = mapImagePath;
  });

  // 异步加载车辆 Logo
  const logoImage = canvas.createImage();
  await new Promise((resolve) => {
    logoImage.onload = resolve;
    logoImage.src = carInfo.logo;
  });

  // 绘制地图底图
  ctx.drawImage(mapImage, 0, 0, this.canvasWidth, this.canvasHeight);

  // 绘制标记（带发光效果）
  this._drawMarker(ctx, carInfo, centerX, centerY, logoImage);

  // 绘制信息卡片
  this._drawInfoCard(ctx, carInfo, location);

  // 导出为 base64 并保存
  const dataURL = canvas.toDataURL();
  const buffer = wx.base64ToArrayBuffer(base64);
  fs.writeFile(filePath, buffer, 'binary');

  return filePath;
}

_drawMarker(ctx, carInfo, x, y, logoImage) {
  // 发光效果
  const gradient = ctx.createRadialGradient(x, y, 0, x, y, 40);
  gradient.addColorStop(0, this._hexToRgba(carInfo.color, 0.3));
  gradient.addColorStop(1, this._hexToRgba(carInfo.color, 0));
  ctx.fillStyle = gradient;
  ctx.beginPath();
  ctx.arc(x, y, 40, 0, Math.PI * 2);
  ctx.fill();

  // 主标记圆圈
  ctx.fillStyle = carInfo.color;
  ctx.beginPath();
  ctx.arc(x, y, 20, 0, Math.PI * 2);
  ctx.fill();

  // 白色边框
  ctx.strokeStyle = 'white';
  ctx.lineWidth = 3;
  ctx.stroke();

  // 车辆 Logo
  ctx.drawImage(logoImage, x - 16, y - 16, 32, 32);
}
```

**关键改进：**
1. 使用 `wx.createOffscreenCanvas()` 替代旧版 API
2. Canvas 使用 `type="2d"` 属性
3. 所有图片加载使用 Promise 正确等待
4. 导出使用 `toDataURL()` + `base64ToArrayBuffer` + 文件系统 API
5. 标记样式与页面 cover-view 保持一致
