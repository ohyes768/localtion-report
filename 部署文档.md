## 2. GitHub Pages部署

### 2.1 快速部署

1. **Fork项目**
   ```bash
   # 访问GitHub页面，点击Fork按钮
   https://github.com/your-username/localtion-report
   ```

2. **克隆到本地**
   ```bash
   git clone https://github.com/your-username/localtion-report.git
   cd localtion-report
   ```

3. **自定义配置（可选）**
   ```bash
   # 编辑配置文件
   vim js/config.js

   # 修改API Key或车辆信息
   ```

4. **推送代码**
   ```bash
   git add .
   git commit -m "Deploy to GitHub Pages"
   git push origin main
   ```

5. **启用GitHub Pages**
   - 进入仓库Settings页面
   - 找到Pages选项
   - Source选择"Deploy from a branch"
   - Branch选择"main"
   - 保存设置

6. **访问应用**
   ```
   https://your-username.github.io/localtion-report/
   ```

### 2.2 自定义域名

1. **创建CNAME文件**
   ```bash
   echo "yourdomain.com" > CNAME
   git add CNAME
   git commit -m "Add custom domain"
   git push origin main
   ```

2. **配置DNS解析**
   - 在域名提供商添加CNAME记录
   - 主机记录: `www`
   - 记录值: `your-username.github.io`

## 3. Docker容器化部署

### 3.1 准备Docker环境

1. **安装Docker**
   ```bash
   # Ubuntu/Debian
   curl -fsSL https://get.docker.com -o get-docker.sh
   sudo sh get-docker.sh

   # CentOS/RHEL
   sudo yum install docker
   sudo systemctl start docker
   ```

2. **安装Docker Compose**
   ```bash
   sudo curl -L "https://github.com/docker/compose/releases/download/v2.20.0/docker-compose-$(uname -s)-$(uname -m)" -o /usr/local/bin/docker-compose
   sudo chmod +x /usr/local/bin/docker-compose
   ```

### 3.2 使用Docker Compose部署

1. **项目结构**
   ```
   localtion-report/
   ├── docker-compose.yml
   ├── nginx.conf
   └── (其他项目文件)
   ```

2. **docker-compose.yml配置**
   ```yaml
   version: '3.8'

   services:
     nginx:
       image: nginx:alpine
       container_name: location-report-nginx
       ports:
         - "8080:80"
       volumes:
         - ./:/usr/share/nginx/html
         - ./nginx.conf:/etc/nginx/conf.d/default.conf
       restart: unless-stopped
       networks:
         - app-network
       environment:
         - NGINX_HOST=localhost
         - NGINX_PORT=80

     redis:
       image: redis:alpine
       container_name: location-report-redis
       ports:
         - "6379:6379"
       volumes:
         - redis_data:/data
       restart: unless-stopped
       networks:
         - app-network
       command: redis-server --appendonly yes

     portainer:
       image: portainer/portainer-ce:latest
       container_name: location-report-portainer
       ports:
         - "9000:9000"
       volumes:
         - /var/run/docker.sock:/var/run/docker.sock
         - portainer_data:/data
       restart: unless-stopped
       networks:
         - app-network

   volumes:
     redis_data:
     portainer_data:

   networks:
     app-network:
       driver: bridge
   ```

3. **nginx.conf配置**
   ```nginx
   server {
       listen 80;
       server_name localhost;
       root /usr/share/nginx/html;
       index index.html;

       # 日志配置
       access_log /var/log/nginx/access.log;
       error_log /var/log/nginx/error.log;

       # Gzip压缩
       gzip on;
       gzip_vary on;
       gzip_min_length 1024;
       gzip_types text/plain text/css text/xml text/javascript application/javascript application/xml+rss application/json;

       # 静态资源缓存
       location ~* \.(js|css|png|jpg|jpeg|gif|ico|svg|woff|woff2|ttf|eot)$ {
           expires 1y;
           add_header Cache-Control "public, immutable";
           add_header Vary Accept-Encoding;
       }

       # HTML文件缓存
       location ~* \.html$ {
           expires 1h;
           add_header Cache-Control "public, must-revalidate";
       }

       # 处理SPA路由
       location / {
           try_files $uri $uri/ /index.html;
       }

       # 安全头
       add_header X-Frame-Options "SAMEORIGIN" always;
       add_header X-Content-Type-Options "nosniff" always;
       add_header X-XSS-Protection "1; mode=block" always;
       add_header Referrer-Policy "strict-origin-when-cross-origin" always;

       # 腾讯地图API缓存
       location ~* ^/(apis\.map\.qq\.com)/ {
           proxy_pass https://apis.map.qq.com/;
           proxy_set_header Host apis.map.qq.com;
           proxy_set_header X-Real-IP $remote_addr;
           proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
           proxy_cache_valid 200 5m;
       }
   }
   ```

4. **启动服务**
   ```bash
   # 启动所有服务
   docker-compose up -d

   # 查看服务状态
   docker-compose ps

   # 查看日志
   docker-compose logs -f nginx

   # 停止服务
   docker-compose down
   ```

5. **访问应用**
   - 主应用: http://your-server-ip:8080
   - Portainer管理: http://your-server-ip:9000

### 3.3 Dockerfile（可选）

如果需要自定义镜像：

```dockerfile
FROM nginx:alpine

# 复制项目文件
COPY . /usr/share/nginx/html

# 复制nginx配置
COPY nginx.conf /etc/nginx/conf.d/default.conf

# 设置权限
RUN chown -R nginx:nginx /usr/share/nginx/html

# 暴露端口
EXPOSE 80

# 启动nginx
CMD ["nginx", "-g", "daemon off;"]
```

构建和运行：
```bash
docker build -t location-report .
docker run -d -p 8080:80 location-report
```

## 4. Nginx静态部署

### 4.1 安装Nginx

```bash
# Ubuntu/Debian
sudo apt update
sudo apt install nginx

# CentOS/RHEL
sudo yum install nginx
sudo systemctl start nginx
```

### 4.2 配置虚拟主机

1. **创建配置文件**
   ```bash
   sudo vim /etc/nginx/sites-available/location-report
   ```

2. **配置内容**
   ```nginx
   server {
       listen 80;
       server_name your-domain.com www.your-domain.com;
       root /var/www/location-report;
       index index.html;

       # 日志
       access_log /var/log/nginx/location-report.access.log;
       error_log /var/log/nginx/location-report.error.log;

       # 静态资源配置
       location / {
           try_files $uri $uri/ /index.html;
       }

       # 静态资源缓存
       location ~* \.(js|css|png|jpg|jpeg|gif|ico|svg)$ {
           expires 1y;
           add_header Cache-Control "public, immutable";
       }
   }
   ```

3. **启用站点**
   ```bash
   sudo ln -s /etc/nginx/sites-available/location-report /etc/nginx/sites-enabled/
   sudo nginx -t
   sudo systemctl reload nginx
   ```

### 4.3 部署代码

```bash
# 创建网站目录
sudo mkdir -p /var/www/location-report
cd /var/www/location-report

# 克隆代码
sudo git clone https://github.com/your-username/localtion-report.git .

# 设置权限
sudo chown -R www-data:www-data /var/www/location-report
sudo chmod -R 755 /var/www/location-report
```

## 5. 阿里云ECS部署指南

### 5.1 购买ECS实例

1. **实例规格**
   - CPU: 1核心
   - 内存: 2GB
   - 存储: 40GB SSD
   - 带宽: 1Mbps

2. **操作系统**
   - Ubuntu 20.04 LTS
   - CentOS 7.x

### 5.2 安全组配置

```bash
# 允许HTTP
sudo ufw allow 80/tcp

# 允许HTTPS
sudo ufw allow 443/tcp

# 允许SSH
sudo ufw allow 22/tcp

# 允许Docker端口（可选）
sudo ufw allow 8080/tcp
sudo ufw allow 9000/tcp
```

### 5.3 域名解析

在阿里云域名解析控制台添加记录：

```
记录类型: A
主机记录: @
记录值: 你的ECS公网IP
TTL: 600

记录类型: A
主机记录: www
记录值: 你的ECS公网IP
TTL: 600
```

### 5.4 SSL证书配置

1. **申请免费SSL证书**
   ```bash
   # 安装Certbot
   sudo apt install certbot python3-certbot-nginx

   # 获取证书
   sudo certbot --nginx -d your-domain.com -d www.your-domain.com
   ```

2. **自动续期**
   ```bash
   # 添加cron任务
   sudo crontab -e

   # 添加以下行
   0 12 * * * /usr/bin/certbot renew --quiet
   ```

## 6. 域名和SSL配置

### 6.1 域名购买和配置

1. **推荐域名服务商**
   - 阿里云万网
   - 腾讯云
   - Cloudflare

2. **DNS配置**
   ```
   A记录: @ -> 你的服务器IP
   A记录: www -> 你的服务器IP
   CNAME记录: api -> 你的API域名（可选）
   ```

### 6.2 SSL证书

#### Let's Encrypt免费证书

```bash
# 安装Certbot
sudo apt install certbot

# 获取证书
sudo certbot certonly --standalone -d your-domain.com

# 配置nginx
ssl_certificate /etc/letsencrypt/live/your-domain.com/fullchain.pem;
ssl_certificate_key /etc/letsencrypt/live/your-domain.com/privkey.pem;
```

#### 阿里云SSL证书

1. 登录阿里云SSL证书控制台
2. 购买免费DV SSL证书
3. 下载证书文件
4. 配置Nginx

### 6.3 HTTPS配置

```nginx
server {
    listen 443 ssl http2;
    server_name your-domain.com;

    ssl_certificate /path/to/cert.pem;
    ssl_certificate_key /path/to/key.pem;
    ssl_protocols TLSv1.2 TLSv1.3;
    ssl_ciphers ECDHE-RSA-AES128-GCM-SHA256:ECDHE-RSA-AES256-GCM-SHA384;
    ssl_prefer_server_ciphers off;

    # HSTS
    add_header Strict-Transport-Security "max-age=63072000" always;

    # 其他配置...
}

# HTTP重定向到HTTPS
server {
    listen 80;
    server_name your-domain.com;
    return 301 https://$server_name$request_uri;
}
```

## 8. 常见问题

### 8.1 部署问题

**Q: 页面无法访问？**
A: 检查以下项目：
- Nginx服务是否启动
- 防火墙端口是否开放
- 域名解析是否正确
- SSL证书是否有效

**Q: 地图不显示？**
A: 检查以下项目：
- API Key是否配置正确
- 网络是否能访问腾讯地图API
- 浏览器控制台是否有错误信息

**Q: 定位失败？**
A: 检查以下项目：
- 浏览器是否允许定位权限
- 是否使用HTTPS（某些浏览器要求）
- 是否在室内环境（建议使用默认位置测试）

### 8.2 性能优化

**启用Gzip压缩**:
```nginx
gzip on;
gzip_types text/plain text/css application/json application/javascript;
```

**设置缓存头**:
```nginx
location ~* \.(js|css|png|jpg|jpeg|gif|ico|svg)$ {
    expires 1y;
    add_header Cache-Control "public, immutable";
}
```

### 8.3 安全加固

1. **隐藏Nginx版本**
   ```nginx
   server_tokens off;
   ```

2. **限制请求大小**
   ```nginx
   client_max_body_size 10M;
   ```

3. **防止恶意请求**
   ```nginx
   if ($request_method !~ ^(GET|HEAD|POST)$ ) {
       return 405;
   }
   ```

### 8.4 故障排除

**查看服务状态**:
```bash
# Docker
docker-compose ps
docker-compose logs nginx

# Nginx
sudo systemctl status nginx
sudo journalctl -u nginx

# 系统资源
df -h
free -h
```

**重启服务**:
```bash
# Docker
docker-compose restart nginx

# Nginx
sudo systemctl restart nginx
```
